# hacker-simulation

A fun, game-like way to learn cybersecurity from absolute zero.

Hacker Simulation is an educational platform for **complete beginners**: no security, networking, or Linux experience needed. You join a fictional white-hat security team, work through short story-driven missions in a simulated browser terminal, watch a network map fill in as you explore, and level up as you learn.

Everything is simulated. Nothing here touches a real system, network, or target.

## What you'll learn

- Using a Linux terminal with confidence
- How computer networks work
- How attackers think, and how defenders stop them
- Web security basics
- Why authorization and ethics come first

## What it will feel like

- **A first win in under 2 minutes**, with no sign-up required
- **Short missions** (5–20 minutes) that play like episodes of a story
- **XP, levels, achievements, and unlockable terminal themes**
- **A friendly mentor** who gives hints, never just the answers, and hints never cost you anything
- **Safe mistakes**: break anything, then hit Reset
