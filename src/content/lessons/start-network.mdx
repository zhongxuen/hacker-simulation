## The one-sentence version

A <Term id="network">network</Term> is two or more computers that can pass each other messages.

Picture a street of houses passing notes. Every house has a number, and every note says which number it's from and which number it's for. That's most of it.

## Why it matters in security

Almost every attack today arrives over a network. And almost every defence starts with knowing what's on your own network: you can't protect a computer you don't know is there. Security teams draw maps of their networks for exactly that reason.

## How it actually works

Every computer on a network has an address, called an <Term id="ip-address">IP address</Term> (IP stands for Internet Protocol, the rules for addressing). It looks like four numbers with dots between them, such as `192.168.60.10`.

Messages travel in small pieces called <Term id="packet">packets</Term>. Each packet carries the address it's from and the address it's for, like the note in the diagram. Computers along the way read the "to" address and pass the packet on, until it arrives.

A computer on a network is often called a <Term id="host">host</Term>. When you want to know whether a host is switched on, you send it a tiny "are you there?" message and wait for the answer.

## Common misconceptions

- **"A network needs the internet."** Two computers in the same room can be a network with no internet at all.
- **"Wifi and a network are different things."** Wifi is one way computers join a network, with radio instead of cables.
- **"Every computer answers when you knock."** Some are set to ignore "are you there?" messages. They're still there.
