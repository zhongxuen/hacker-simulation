## The one-sentence version

A <Term id="terminal">terminal</Term> is a window where you talk to a computer by typing instead of clicking. Each instruction you type is called a <Term id="command">command</Term>.

Think of it like texting a very literal friend. You send one clear message, and it replies with exactly what happened. Try it now: the box below is a real practice terminal.

## Why it matters in security

Most of the computers that run websites, shops and banks don't have a screen or a mouse. They sit in a building somewhere, and the people who look after them type commands. Attackers type commands too. So if you want to protect a computer, or find out what happened to one, a terminal is where you'll spend your time.

It's also faster than clicking once you know a few commands. One line can search thousands of files.

## How it actually works

Every line starts with a <Term id="prompt">prompt</Term>, like `recruit@range-ws-01:~$`. It tells you who you are, which computer you're on, and which folder you're in. When you see it, the computer is ready.

You type a command's name, sometimes followed by extra settings called <Term id="command-option">options</Term>, like the `-a` in `ls -a`. Then you press Enter, the computer does it, and the answer appears underneath.

## In practice

In your first mission, [Welcome to the team](/missions/intro-01), you'll type `whoami` and `ls` on your own practice computer, with a short tour pointing at where to type. Type `help` in any terminal here to see every command, grouped by what it's for.

## Common misconceptions

- **"The terminal is only for experts."** Everyone starts with three or four commands. You've already used two.
- **"One wrong command could wreck the computer."** On a real computer, a few commands can delete things, so professionals read before they press Enter. Here, nothing is real, and Reset machine puts everything back.
- **"It's a different program from the rest of the computer."** It's another way into the same files and programs you'd reach by clicking.
