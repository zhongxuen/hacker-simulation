## The one-sentence version

A computer is a machine that keeps <Term id="file">files</Term>, runs programs that work on them, and decides which person is allowed to do what.

Think of an office building. The filing cabinets are the files. The staff doing the work are the programs. Everyone who comes in gets a key card, and each card opens some doors and not others.

## Why it matters in security

Almost every attack is about getting into a room you shouldn't be in: reading a file that holds passwords, or running a program with more power than you're meant to have. Almost every defence is about the key cards: making sure each person, and each program, can open only the doors they need.

So the question security people ask again and again is: who can do what here?

## How it actually works

A computer has four parts worth knowing:

- **Files** hold everything: letters, photos, settings, passwords. They sit in <Term id="directory">folders</Term>, and folders sit inside other folders.
- **Programs** are files that do things when they run, like a web browser or a calculator.
- The <Term id="operating-system">operating system</Term> is the program in charge of all the others. Windows, macOS and Linux are operating systems.
- A <Term id="user-account">user account</Term> is your key card. Every file has <Term id="permissions">permissions</Term> that say which accounts may read it, change it, or run it.

## Try it

On this practice computer you're the account `recruit`. Ask which account you are, then list your files with their permissions. The letters at the start of each line, like `-rw-r--r--`, are the lock on that file.

Now try `cat /home/kit/plans.txt`. The computer refuses: that file belongs to Kit, and its lock lets nobody else in. That refusal isn't a mistake. It's the protection working.

## Common misconceptions

- **"If it's on my computer, I can see all of it."** Even on your own laptop, some files belong to the operating system and your everyday account can't change them. That keeps a mistake, or a bad program, from breaking everything.
- **"Folders and files are different things."** A folder is a special kind of file that holds a list of other files.
- **"Only people have accounts."** Programs often run under their own accounts too, so a program that goes wrong can only reach what its account can.
