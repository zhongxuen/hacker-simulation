# src/features/network-visualizer

The fog-of-war network map (phase 07). It renders what the learner has discovered, and nothing else: whoever owns the simulation state calls `selectTopology(state)` from `@/sim` and passes the result in. Nothing here reads or changes simulation state.

- `components/network-map-panel.tsx`: `NetworkMapPanel`, the whole map as the mission workspace and the sandbox use it. Props: `topology`, `events` (every event since the run began), `notes?` and `onNoteChange?`, `tip?` (the mentor's first-discovery line), `title?`, `exportName?`. It shows the drawing or the table (the `networkView` setting, toggled in its header), a "found so far" count that never says what's left, a "Host found!" pop and an `aria-live` announcement for each discovery, the details panel for the picked host, and Export.
- `components/topology-graph.tsx`: `TopologyGraph`, the SVG map (`"use client"`). Props: `topology`, `selectedHostId?`, `onSelectHost?`, `showLegend?`, `className?`. Pan by dragging, zoom with the wheel, a pinch or the zoom buttons. With a card focused: arrow keys move between cards, Enter or Space opens its details, `+`/`-` zoom, `0` fits, Shift + arrow keys scroll. One card is in the Tab order at a time. Under the map, the hovered or focused card's state is explained in words.
- `components/topology-table.tsx`: `TopologyTable`, the same information as a sortable, filterable table (Host, IP, Subnet, State, OS, Services, Reachable from), plus the networks list and a state key. `table.ts` lists what the drawing shows and where the table says it; `tests/unit/network-map.test.ts` checks the table carries all of it.
- `components/host-inspector.tsx`: `HostInspector`, everything known about one host: addresses and networks, state, OS guess, services with ports, programs and banners, which command revealed each (`discovery-log.ts`), and the learner's notes (kept in the mission run, in memory).
- `components/export-menu.tsx`, `export.ts` and `export-client.ts`: Export as a PNG (a standalone SVG drawn from the layout, coloured from the design tokens at export time, turned into a picture on a canvas) or JSON. Both are stamped "SIMULATED - not a real network". Nothing leaves the device.
- `components/map-layers.tsx`, `node-glyph.tsx`, `topology-legend.tsx`: the drawing, each state's shape and colour, and the map key.
- `layout.ts`: the pure, deterministic layout. `view.ts`: pure pan and zoom maths. `announce.ts`: what's new between two topologies, as a sentence. `copy.ts`: every word the map shows.

New hosts pop in, but only up to `MAX_POPPING_NODES` of them at once (`components/topology-graph.tsx`): each pop is an SVG transform animation the browser repaints every frame while it runs, so a couple of hundred together cost the map a third of its frame rate. A scan finds a handful, so the reveal moment is untouched. Measured, not assumed: `tests/e2e/network-map-performance.spec.ts` prints the frame times at 200 hosts and fails on a regression; `tests/components/topology-graph-reveal.test.tsx` locks in which cards animate.

Rules: semantic colour tokens only (`tests/unit/no-hardcoded-colours.test.ts`), motion only through `src/styles/motion.css` utilities (so reduced motion snaps), never colour alone for a host's state (each has a shape and a word: "Heard of", "Found", "Scanned", "Accessed"), and no counts of what's left to find. Tests: `tests/unit/topology-layout.test.ts`, `tests/unit/topology-graph.test.ts`, `tests/unit/network-map.test.ts`, `tests/components/topology-graph-reveal.test.tsx` and `tests/e2e/network-map-performance.spec.ts`.

Public API: `index.ts` only. Never import here: another feature's internals, or runtime code from `@/sim` (types from `@/sim/types` are fine).
