## The one-sentence version

People remember names and computers need numbers, so every network has a way to turn a name like `orders-01.tumbleloaf.example` into an address like `10.40.2.15`. On the internet, that name is a <Term id="domain-name">domain name</Term>, and the system that looks it up is <Term id="dns">DNS</Term> (the Domain Name System).

It's your phone's contacts list: you tap "Roz", and the phone dials the number. Try it with a name on the Range:

Your own computer has a name too: type `hostname` to see it.

## Why it matters in security

If someone can change the answer to "what's the address for this name?", they can send people to the wrong place without them noticing. The name in the address bar looks right, but the computer behind it is someone else's. That's why DNS settings are guarded closely, and why security teams watch for lookups of strange names.

Names also leak information. A computer called `backup-01` or `payroll-db` tells an outsider exactly what it's for, before they've knocked on a single door.

## How it actually works

An <Term id="ip-address">IP address</Term> is what messages actually travel to. A name is a label for people. When you type a name, your computer asks a DNS server "what's the address for this?", gets a number back, and then sends its message to that number. Answers are remembered for a while, so the next lookup is instant.

Names are read from right to left, from the biggest group to the smallest, like a postal address written backwards:

Where the contacts-list analogy breaks down: your contacts belong to you, but DNS answers come from servers you don't control, run by other people. You're trusting them to tell the truth, which is exactly what makes a false answer dangerous.

## Common misconceptions

- **"DNS is the internet."** DNS is the phone book, not the phone network. If DNS breaks, the internet is still there, but people can't find anything by name. Typing an address directly still works.
- **"A name can only point to one address."** A busy website's name can point to many addresses, and a name's address can change. That's why investigators write down both, with the time.
- **"If the name looks right, it's the real site."** A name that looks right can still be pointed somewhere else, or be a lookalike with one letter changed. The padlock and the exact spelling both matter.
